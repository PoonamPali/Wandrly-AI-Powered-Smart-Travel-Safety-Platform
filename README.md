# Wandrly — AI Powered Smart Travel & Safety Platform 🌍✈️

Wandrly is a modern AI-powered smart travel web application designed to provide personalized travel planning, budget management, and safety-focused features through an interactive and responsive user experience.

This platform combines intelligent travel assistance with modern UI/UX design to enhance trip planning and improve traveler safety.

---

Features

- AI-Based Itinerary Generator
- Mood-Based Travel Recommendations
- Smart Budget Planner
- Budget Comparison System
- SOS Emergency Support
- Travel Scam Awareness Feature
- Group Travel Matching Concept
- Interactive Chat Assistant
- Dynamic Booking Simulation
- Responsive Modern UI
- Dark & Light Theme Toggle

---

Tech Stack

- HTML5
- CSS3
- JavaScript
